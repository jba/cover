# Implementation contract

Module github.com/jba/cover. CLI at the module root. No external dependencies.

Internal package `internal/instrument` exports:
- Position {Line int `json:"line"`; Column int `json:"column"`}
- Range {Start Position `json:"start"`; End Position `json:"end"`}
- Point {File string `json:"file"`; Kind string `json:"kind"`; Construct string `json:"construct,omitempty"`; Outcome string `json:"outcome,omitempty"`; Range Range `json:"range"`; Statements int `json:"statements,omitempty"`; Counter int `json:"-"`}
- Instrument(filename string, src []byte, prefix string, nextCounter *int) ([]byte, []Point, error)

prefix is a valid reserved-ish identifier prefix unique to this package, e.g. __cover_a1b2. Instrumentation references prefix+"Hit"(counterID) and prefix+"Bool"(trueID,falseID, bool-expression) (a generic ~bool-preserving helper). Counters increment (not set), using in-memory atomic.Uint64 values in a per-package runtime supplied by CLI. IDs allocate by incrementing *nextCounter, zero-based.

CLI at internal/runner, exported Run(ctx context.Context, args []string, stdout, stderr io.Writer) error. Root main.go just invokes runner.Run. Flags -o filename (default stdout JSONL), -run, -count (default 1), -timeout, -tags, -race. Positional package patterns default '.'; list packages via go list -json and instrument their non-test GoFiles/CgoFiles only. Use original-source absolute filenames in JSONL, ranges line/byte-column 1-based exclusive end. Compile rewritten sources through go test -overlay with virtual generated runtime Go file added inside each original package directory. Never copy modules or modify source. Tests' output to stderr, stdout exclusively JSONL.

Runtime strategy: ordinary zero-initialized [N]atomic.Uint64 arrays retain hits from original global initializers. Each package registers a JSON exporter with a shared generated registry package, supplied as a public virtual directory in a selected module. It imports no original packages, avoiding cycles and internal-import restrictions. Exporters atomically load counters and write temporary JSON files, then rename them to package-specific PID snapshot files. Repeat saves replace the process's previous snapshot; the driver merges different processes' snapshots.

TestMain persistence: every tested selected package gets a generated TestMain if it has none, including packages with no original tests. Existing TestMain (internal or external) gets a deferred registry.Flush for normal return. Direct imported os.Exit calls inside its body become registry.Exit(originalExit, code), where the registry saves then invokes originalExit; this preserves deferred/go call timing and keeps the os import used. Lexical resolution handles aliases, dot imports, and local shadows. No runtime exit hooks are used; abnormal exits outside these save paths may lose counters. Save errors produce diagnostics and a failing exit status. Automatic vet is disabled because it cannot chdir to a virtual registry directory; vet can run separately on original source. Module mode is required. There is no OS-specific runtime code.

Loops: local bool declared at function entry; first body entry sets bool and hits entered branch counter. After loop, if !bool hit skipped counter. This captures skipped only on normal zero-iteration completion and does not misclassify initial-expression panics. Infinite for has entered obligation only (skipped structurally impossible).

Goto support: generated loop and switch flags are hoisted to function entry, before all original labels and declarations. No extra blocks surround these controls. A control's branch-state reset is inserted before its labels. Resolve labels to their unwrapped statements within each function, excluding nested function literals. Insert the target's reset immediately before each goto keyword, after any labels on that goto. Native coverage probes are never replayed: retain their original Go probe placement, even where a jump bypasses a header probe. Original loop/switch labels stay attached, preserving labeled break/continue. Reserve the declaration edit before branch edits to handle identical offsets in compact source. Declare/reset/set flags with 0!=0 / 0==0 so shadowed bool/true/false identifiers do not interfere.

Statement coverage: internal/blockcover runs the selected `go tool cover -mode=count` on original bytes, reads native Pos/NumStmt metadata, and extracts the exact probe/else-wrapper insertions. Recover original offsets only by exact untouched-chunk comparison, rejecting unknown output changes. Replace each native increment with an atomic runtime Hit; remove the legacy metadata declaration and injected //line header. Native insertion edits are merged with branch-only edits into the original source. Block planning never sees generated branch statements. Statement points represent native coverage blocks with their statement weights, including empty zero-weight blocks. File identity stays physical; coordinates follow the native toolchain (which may honor //line). Legacy field-width limits are conservatively rejected. Branch coverage: if true/false (physical condition range); for/range entered/skipped (physical header range). Switch/type-switch/select clauses are instrumented as entry branch points; switches without defaults also have a no-match point. Conditions a||b are not split in initial version.
