# Implementation contract

Module github.com/jba/cover. CLI at the module root. No external dependencies.

Internal package `internal/instrument` exports:
- Position {Line int `json:"line"`; Column int `json:"column"`}
- Range {Start Position `json:"start"`; End Position `json:"end"`}
- Point {File string `json:"file"`; Kind string `json:"kind"`; Construct string `json:"construct,omitempty"`; Outcome string `json:"outcome,omitempty"`; Range Range `json:"range"`; Counter int `json:"-"`}
- Instrument(filename string, src []byte, prefix string, nextCounter *int) ([]byte, []Point, error)

prefix is a valid reserved-ish identifier prefix unique to this package, e.g. __cover_a1b2. Instrumentation references prefix+"Hit"(counterID) and prefix+"Bool"(trueID,falseID, bool-expression) (a generic ~bool-preserving helper). Counters increment (not set), using in-memory atomic.Uint64 values in a per-package runtime supplied by CLI. IDs allocate by incrementing *nextCounter, zero-based.

CLI at internal/runner, exported Run(ctx context.Context, args []string, stdout, stderr io.Writer) error. Root main.go just invokes runner.Run. Flags -o filename (default stdout text report), -run, -count (default 1), -timeout, -tags, -race, -v (show source excerpts). Positional package patterns default '.'; list packages via go list -json and instrument their non-test GoFiles/CgoFiles only. Compile rewritten sources through go test -overlay with virtual generated runtime Go file added inside each original package directory. Never copy modules or modify source. Tests' output to stderr, stdout exclusively the coverage report.

Report format: one `FILE START END WORD` record per missing reported obligation, where FILE is the unquoted absolute original-source filename and START/END are physical 1-based line:byte-column positions, exclusive end. Parse the last three space-delimited fields from the right to support filenames containing spaces. Reject filenames containing CR/LF rather than emitting malformed records. WORD is `uncovered` for statement points, or `skipped` for if/false, for/skipped, and switch or type-switch/no-match. Other internal branch outcomes are not printed; nonempty bodies are represented by their statement points. Empty bodies have no statement records. Sort by filename, start/end position, and word. Internal point metadata and atomic-counter snapshots are unchanged; JSON is used for snapshots and overlays, not the public report.

Verbose report: -v appends the complete physical source lines START.Line through END.Line inclusive below each record, ignoring both columns (including END.Column==1). Prefix each source line with four spaces; preserve original indentation and blank lines, normalize CRLF to LF, and terminate every displayed line with LF. Repeat lines for overlapping records. Read original files on demand during reporting and cache each file's lines for the entire report; do not read sources for covered/filtered points or in nonverbose mode. Report missing sources, invalid line bounds, and write failures as errors. -o redirects the entire verbose report. -v is not passed to go test, and -v=false retains record-only output.

Runtime strategy: ordinary zero-initialized [N]atomic.Uint64 arrays retain hits from original global initializers. Each package registers a JSON exporter with a shared generated registry package, supplied as a public virtual directory in a selected module. It imports no original packages, avoiding cycles and internal-import restrictions. Exporters atomically load counters and write temporary JSON files, then rename them to package-specific PID snapshot files. Repeat saves replace the process's previous snapshot; the driver merges different processes' snapshots.

TestMain persistence: every tested selected package gets a generated TestMain if it has none, including packages with no original tests. Existing TestMain (internal or external) gets a deferred registry.Flush for normal return. Direct imported os.Exit calls inside its body become registry.Exit(originalExit, code), where the registry saves then invokes originalExit; this preserves deferred/go call timing and keeps the os import used. Lexical resolution handles aliases, dot imports, and local shadows. No runtime exit hooks are used; abnormal exits outside these save paths may lose counters. Save errors produce diagnostics and a failing exit status. Automatic vet is disabled because it cannot chdir to a virtual registry directory; vet can run separately on original source. Module mode is required. There is no OS-specific runtime code.

Loops: local bool declared at function entry; first body entry sets bool and hits entered branch counter. After loop, if !bool hit skipped counter. This captures skipped only on normal zero-iteration completion and does not misclassify initial-expression panics. Infinite for has entered obligation only (skipped structurally impossible).

Goto support: generated loop and switch flags are hoisted to function entry, before all original labels and declarations. No new blocks surround these controls. Each original statement has an entry prelude (statement counter, plus a flag reset where needed) inserted before its labels. Resolve labels to their unwrapped statements within each function, excluding nested function literals. Insert the target's prelude immediately before each goto keyword, after any labels on that goto. Jumps therefore cannot bypass target coverage or resets; the original loop/switch labels stay attached, preserving labeled break/continue. Block and empty statements need no entry prelude. Reserve the declaration edit before statement edits to handle identical offsets in compact source. Declare/reset/set flags with 0!=0 / 0==0 so shadowed bool/true/false identifiers do not interfere.

Statement coverage: executable original statement regions (not generated code), count on entry. Control statements use header ranges rather than spanning bodies. Branch coverage: if true/false (condition range); for/range entered/skipped (header range). Switch/type-switch/select clauses are instrumented as entry branch points; switches without defaults also have a no-match point. Conditions a||b are not split in initial version.
